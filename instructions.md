University of Sri Jayewardenepura, Sri Lanka
Bachelor of Information and Communication Technology Semester 4
IIC 2223 Web Application Development
Laboratory Exercise 1 – Part 1
AI Web Application Challenge
Mode: Group work, unrestricted use of AI
Working time: 60 minutes
Aim: Create the best working web application your group can within one(1)
hour.
Choose any useful topic or real-world problem. It may relate to the university, an
organisation, the student community, or your proposed final project. Build a
working web application using AI tools as extensively and creatively as you wish.
Start here
1. Choose the problem, intended users, and one essential user journey.
2. Use AI tools to design and build the application.
3. Test the essential journey and repair obvious failures.
4. At 60 minutes, stop and preserve the exact submitted version.
Tools you may use
• Prompt-to-app: Lovable, Bolt, Replit Agent, v0, Base44, Bubble AI, Figma Make
or FlutterFlow.
• AI coding/IDE tools: GitHub Copilot, Cursor, Codex, Claude Code, Windsurf,
Cline, Roo Code or JetBrains Junie.
• General AI assistants: ChatGPT, Claude, Gemini or similar tools.
AI generation is not limited to typed prompts. You may use voice instructions,
screenshots, sketches, uploaded specifications, templates, existing repositories,
inline code completion, quick fixes and autonomous/agent modes. Record every
important instruction or input used.
Submission: exactly two (02) items
Only the group leader or one nominated member should upload the submission.
1. The application
Submit either:
• a working application URL; or
• the complete application files/repository.
Submit both when available. Include any essential access or run instructions
in the document below. Do not submit passwords, API keys or other secrets.
2. One group document (PDF preferred) with the following.
• group number and project title
• every member's name and index number
• leader/nominated submitter
• problem, intended users and a short project summary
• main features and technologies/tools used
• all prompts and follow-up prompts used
• other AI-generated actions or inputs, such as voice instructions, screenshots,
uploaded files, templates, code completions or agent actions
• a brief note on what the group tested before submission
Prompt/tool histories may be copied, exported or shown with readable
screenshots. Keep the document concise but complete enough to reproduce how
the application was produced.
Important
• Preserve a copy of the exact application submitted at the 60-minute deadline.
• A polished appearance is useful, but a working and testable application is
more important.
How to Submit:
Create a zipped file with two items (the project and the PDF document).
Name the zipped file with the Group number, name, or the index number of the
representative and submit to the LMS using the provided link.
Only the group leader or one nominated member should upload the submission.
